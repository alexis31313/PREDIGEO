### 1.2 Descripción de la Obra

PrediGeo es una aplicación móvil desarrollada como herramienta de investigación para la evaluación de la precisión del sistema GNSS en dispositivos móviles. El software permite:

- Captura de coordenadas geográficas mediante GPS del dispositivo
- Cálculo automático de áreas (polígonos) y distancias (trayectos)
- Procesamiento de señal GNSS mediante filtros de Kalman y promedios ponderados
- Almacenamiento local de datos en base de datos SQLite
- Evaluación de precisión mediante comparación con valores de referencia
- Exportación de resultados en formato CSV
- Funcionamiento completamente offline

El código fuente comprende aproximadamente 4,000 líneas distribuidas en 30+ archivos Dart, organizados siguiendo el patrón de arquitectura limpia (Clean Architecture) con capas de presentación, dominio y datos.
